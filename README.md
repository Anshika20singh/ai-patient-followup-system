# MediCare AI – Patient Follow-up System

## About the Project
MediCare AI is a healthcare management application designed to support patient follow-ups, medicine reminders, appointment management, and staff monitoring.

## Key Features
- Admin Login with Google Authentication
- Patient Management
- Medicine Management
- Appointment Tracking
- Patient Follow-up Management
- Attention Center
- Dashboard for staff

## Technologies Used
- React.js
- TypeScript
- Vite
- Firebase
- CSS

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Anshika20singh/ai-patient-followup-system.git
   ```

2. Open the project folder:
   ```bash
   cd ai-patient-followup-system
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open the localhost URL displayed in your terminal.

## Project Objective
To simplify healthcare follow-up activities and help healthcare staff manage patient-related information more efficiently.
